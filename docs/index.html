B站评论批量删除 v2.2.202

油猴脚本。只删除当前登录账号自己的评论，不能删别人的。

安装脚本 · 源码 · v2.2.202 发布

安装

  1. 安装 Tampermonkey。
  2. 打开上面的安装链接，或把 bilibili-comment-deleter.user.js 全文粘进新脚本。
  3. 打开任意 *.bilibili.com 页面，点右下角按钮。
  4. 版本号应显示 v2.2.202。停用自己改过的旧副本。

能做什么

来源范围
AICU视频、动态、专栏等它能查到的自己的评论。不是官方实时全量。
官方历史最近看过的视频。不是全部历史，楼中楼只补有限的第一页。
导入本工具导出的 JSON / CSV。可以先备份再删。

删除时怎么算

  • 接口回 code=0 只表示受理，不表示已经删掉。
  • 开了回查：先查单条。还在就降速重试。确认框里的时间是下限。
  • 没开回查：受理的记为待确认，结果不是「完成」。
  • 番剧（type=11）的 csrf 放在网址参数里。
